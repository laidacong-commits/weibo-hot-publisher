# 观点角度与写法

只在需要选题或润色时读取。以下是分析方向与写作练习，不是已核实新闻，不得不经查证直接发布。

## 从新闻事实走到判断

先问三个问题：表面变化是什么；变化影响谁的钱、时间、权利或选择；什么已有事实支持这个判断。先内部写明判断和理由，再压成微博，后台分析不拼进正文。

| 用户关注的汽车话题 | 可以查证并分析的角度 | 避免直接推导 |
| --- | --- | --- |
| 比亚迪经营现金流 | 经营现金流与利润的区别；预收款、应收和应付变化；经营现金与投入的关系 | 一个现金流数字就证明所有财务问题不存在 |
| 比亚迪海外销量 | 出口与终端零售口径；当地需求、渠道和产品组合；销量与利润是否同步 | 把出货量等同当地卖掉、把增速等同利润 |
| 张雪机车与张雪 | 报道中究竟变化的是股权、控制权、经营职务还是品牌叙事 | 把口号当成已完成的股权事实 |
| 小区停车放电赚钱 | 车主净收益如何结算；物业、运营方和车主怎样分配；电池损耗、车位和接入条件 | 把宣传中的毛收入当成车主保证收益 |
| 上汽奥迪清仓四环车型 | 四环与 AUDI 的定位、车型和渠道；南北合资竞争的成本是否落到消费者 | 把某地或部分车型促销说成整个品牌退市 |
| 吉利销量增长 | 销量结构、单车收入、利润与售后能力，统计范围是否包含不同品牌 | 只有销量排名，再接“未来可期” |

## 用户想要的深度

用户提出过“油车选四环，电车看 AUDI；南北合资分头投入是否不够聚焦”的思考。可学习的方式是：从品牌识别、组织投入或消费者选择解释事件；仍要核实具体车型、品牌定位和合资安排，不能把这个判断套进所有奥迪新闻。

下面为排版与表达示例，只有对应前提已核实且准确话题在本次榜单时才可采用：

```text
南北各卷各的未必是好事
用户看的是车和价格
不会替合资公司的分工买单
品牌定位越分越细
渠道和产品反而更该集中
不然省下来的只是用户的耐心
#准确榜单话题#
```

另一种写法，把利益关系讲清楚，而不指控未证实的动机：

```text
小区放电赚钱先把账算明白
电费差价能赚多少
电池损耗由谁承担
收益怎么分给车主
这些得比宣传里的赚钱更清楚
不然热闹归项目成本归车主
#准确榜单话题#
```

示例里的条件、疑问与判断要保留；原始资料没有给出成本和损耗结论，就不能改成“必亏”“骗局”或“车主已经承担了损失”。

## 修稿方法

- 先删通稿铺垫，第一行说清支持、质疑或真正关注的点。
- 一条微博围绕一个判断，用一两个关键事实支撑，避免堆年份、数字和机构名。
- 句子书面化时读一遍，改成平时会对朋友说的话；不要为了“人味”编造“我刚买过”“身边朋友都”。
- 观点不够时补足事实到判断的解释，而不是多加“离谱、笑死、真敢说”。
- 一次修订先解决具体问题。仅空行或首尾空白错误由程序处理，不再启动模型写新稿。
